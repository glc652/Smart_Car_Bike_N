# 一、赛事简介

“单车定向组”属于第二十一届全国大学生智能汽车竞赛室外赛道组别之一。

该组别要求参赛队制作一辆：

- **自主平衡**
- **自主导航**
- **可完成复杂地形通过**
- **具备定向能力**

的电动单车。

本届相比往届：

- 取消了动量轮辅助平衡
- 更强调：
  - 转向控制
  - 姿态稳定
  - 惯性导航
  - 室外复杂环境适应能力



------

# 二、队伍要求

- 每队人数：**3 人**
- 允许指导教师
- 使用指定 MCU 平台
- 允许使用摄像头、IMU、编码器、GPS、电磁等传感器



------

# 三、车辆要求

## 1. 必须为电动单车

要求：

- 单轮前后结构
- 依靠自身实现动态平衡
- 不允许外部支撑结构

------

## 2. 禁止使用的平衡方式

明确禁止：

- 负压吸附平衡
- 动量轮平衡
- 超宽轮胎维持平衡

轮胎宽度限制：

- ≤ 1.6 cm

# 四、比赛科目

单车定向组共包含多个比赛项目。

------

# 科目 1：往返直线竞速

## 目标

完成：

- 直线加速
- 到达终点
- 返回起点

## 重点考察

- 高速稳定性
- 直线控制
- IMU 姿态稳定
- 速度环控制
- 转向抗扰能力

# 科目 2：八字慢速

## 目标

完成低速八字绕行。

## 重点考察

- 慢速平衡能力
- 小角度转向控制
- 低速闭环控制
- 转向与速度融合

------

## 八字规则特点

车辆：

- 只能单向运行
- 不允许来回倒车
- 必须连续完成绕行

官方规则中强调：

> 车辆运行轨迹只能按规定方向穿越路径。

# 五、核心技术方向

------

# 1. 单车自平衡

核心问题：

- 单车天然不稳定
- 需要实时调整转向实现平衡

------

## 常用方法

### （1）角度环

使用：

- IMU
- 陀螺仪
- 卡尔曼滤波

控制：

- 车身倾角

------

### （2）速度环

控制：

- 前进速度
- 慢速稳定性

------

### （3）转向控制

通过：

- 舵机
- 前轮偏角

维持：

- 横向稳定

------

# 2. 姿态融合

常见方案：

- 卡尔曼滤波
- 互补滤波

融合：

- 加速度计
- 陀螺仪
- 编码器

------

# 3. 室外导航

可能使用：

- GPS
- 电磁
- 惯导
- 视觉

------

# 七、常见难点

------

# 1. 慢速容易倒车

原因：

- 速度过低
- 陀螺积分漂移
- 转向不足

------

# 2. 草地稳定性差

原因：

- 摩擦变化
- 打滑
- 姿态震荡

------

# 3. 坡道偏航

原因：

- 重力分量
- 左右轮受力不均

------

# 4. 电磁门识别不稳定

原因：

- 环境干扰
- 电磁信号衰减

------

# 八、推荐调试顺序

```
1. IMU 姿态稳定
2. 编码器测速
3. 直线平衡
4. 转向控制
5. 慢速控制
6. 八字绕行
7. 坡道测试
8. 草地测试
9. 电磁导航
10. 全流程状态机
```

# 十、比赛核心能力总结

单车定向组本质上综合考察：

- 自平衡控制
- 室外导航
- 多传感器融合
- 状态机设计
- 路径规划
- 复杂地形适应
- 嵌入式实时控制

是智能车竞赛中：

- 控制难度较高
- 工程量较大
- 系统综合性极强

的组别之一。
